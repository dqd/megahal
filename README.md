# MegaHAL for Python 3

[MegaHAL](https://en.wikipedia.org/wiki/MegaHAL) is a conversation simulator
from 1998 by Jason Hutchens. It learns from everything you tell it and replies
with sentences generated by a Markov chain, picking the reply which is the most
surprising given the keywords in your input. The results are often nonsensical
and sometimes weirdly on point.

This is a pure Python 3 implementation with no dependencies, published on PyPI
as [megahal3](https://pypi.org/project/megahal3/). It is a port of the Python 2
package `megahal` by Chris Jones to Python 3.8 and higher.

## Installation

```
pip install megahal3
```

The import name stays `megahal`, so existing code written for the Python 2
package keeps working.

## Chatting from the command line

The package installs a `megahal` command. Run it, type something and end the
session with Ctrl-D:

```
$ megahal
>>> Hello, my name is Pavel.
I don't know enough to answer you yet!
>>> I like trains and penguins.
Hello, my name is pavel.
```

The bot knows nothing at first, so give it something to read. A training file
is a plain text file with one sentence per line (lines starting with `#` are
ignored):

```
megahal --train corpus.txt
```

Options:

```
-b, --brain <file>     location of the brain (default: ~/.pymegahal-brain)
-o, --order <int>      order of the Markov chain (default: 5)
-t, --timeout <float>  how long to look for the best reply, in seconds (default: 1.0)
-T, --train <file>     train the brain with a text file before chatting
```

## Using it as a library

```python
from megahal import MegaHAL

with MegaHAL() as megahal:
    megahal.train("corpus.txt")          # learn from a file, one sentence per line
    megahal.learn("Penguins can't fly.")  # learn from a single phrase
    print(megahal.get_reply("Tell me about penguins"))
```

`MegaHAL(order=None, brainfile=None, timeout=None)` accepts the same
parameters as the command line options above. The brain is opened on creation
and flushed to disk when the context manager exits or when you call `close()`.
You can also call `sync()` to flush changes without closing.

Methods:

- `train(file, encoding="utf-8")` learns every non-empty line of a text file.
- `learn(phrase)` learns from a phrase without replying.
- `get_reply(phrase)` learns from a phrase and returns a reply to it.
- `get_reply_nolearn(phrase)` returns a reply without changing the brain.
- `interact()` runs the interactive session used by the command line tool.
- `sync()` and `close()` flush changes to disk.

The word lists which drive keyword selection are stored in the brain and can
be changed through the `banwords`, `auxwords` and `swapwords` properties:

```python
megahal.banwords.append("PENGUIN")   # never use as a keyword
megahal.auxwords.append("TRAIN")     # use as a keyword only alongside other keywords
megahal.swapwords["MINE"] = "YOURS"  # replace in keywords
```

Words are stored in upper case, so use upper case in these lists too.

## The brain file

The brain is a [shelve](https://docs.python.org/3/library/shelve.html)
database, stored by default in `~/.pymegahal-brain` (depending on the platform
the file may get a suffix like `.db`). A brain is tied to the order of its
Markov chain, opening it with a different `order` raises `ValueError`.

Brains created by the Python 2 package cannot be opened, they contain Python 2
pickles. Train a new brain from your text instead.

Brain files are plain pickles of Python objects and are not portable across
operating systems using different `dbm` backends.

## Changes from the Python 2 package

Besides running on Python 3, this port fixes a few differences from the
original C implementation of MegaHAL which affected the quality of replies:

- Generating and scoring candidate replies no longer modifies the brain. In the
  Python 2 package every reply attempt was learned as if it had been said, so
  the brain filled up with its own babble and `get_reply_nolearn()` did not
  live up to its name.
- Candidate replies are scored before the context is advanced, as in the C
  code, so the surprise of a reply is measured correctly.
- A candidate reply is rejected when it repeats the input phrase, not when it
  happens to equal the list of keywords.
- Phrases ending with an apostrophe or consisting of a single word no longer
  crash the tokenizer.
- The command line tool is now a console script entry point built on
  `argparse`, so `megahal --help` and `megahal --version` work as expected.
- `MegaHAL` can be used as a context manager and accepts `pathlib.Path`
  objects as the brain file.
